# Architectural Decision Records (ADRs)

This directory records all significant architectural and operational decisions using the [MADR (Markdown Any Decision Records)](https://adr.github.io/madr/) format.

New decisions should be proposed by copying [`template.md`](template.md) into a sequentially numbered file (e.g. `0002-title.md`).
