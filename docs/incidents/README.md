# Security Incident Reports

This directory stores post-incident analysis reports and root cause investigations for security events, intrusion attempts, and credential leaks.

## Structure & Conventions

- Each incident is documented as a standalone markdown file named `YYYY-MM-DD-<short-slug>.md` (e.g. `2026-11-12-leaked-api-token.md`).
- To create a new report, copy [`template.md`](file:///Users/ruslan/dnu-is-2/server-1/docs/incidents/template.md) and fill out each section.
- **Confidentiality Notice**: When committing reports to version control, adhere to the secrets policy in [`AGENTS.md`](file:///Users/ruslan/dnu-is-2/server-1/AGENTS.md). Sanitize all plaintext passwords, production API tokens, and real internal IP addresses before publishing.
